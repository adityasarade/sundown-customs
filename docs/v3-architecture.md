# Sundown Customs v3 — "Heist Night" architecture contract

Shared source of truth for parallel builders. `src/city.ts` (road grid, landmarks, map projection, `Mission`), `src/gps.ts` (next-turn logic) and `src/editor-contexts.ts` (Unlayer contexts incl. `plan`, `ink`, `hijack`) already exist — import them, do not fork them. `src/App.tsx`, `src/Editor.tsx` and `src/audio.ts` are owned by the integrator / another job: do NOT edit them. Each module owns only the files listed for it. Put component CSS in the module's own `.css` file imported from its component. Other builders edit other files at the same time: if `npx tsc -b` reports errors only in files you do not own, ignore them; your own files must typecheck against these contracts.

Style: React 19 + TypeScript strict, three.js r183, lucide-react. Palette: pink #ff4fb0, cyan #52e8ff, sunset #ff8a5c, gold #ffcf4a, cream #f0ead9, ink #141323, red #ff3b4e, green #7ee07a. Fonts: "Barlow Condensed" (display, 800–900, often italic with black outline) and "DM Sans". GTA-VI loading-screen tone; satirical, original names only (no real brands/Rockstar marks).

## World coordinates
x = east, z = south (north is −z; heading 0 drives toward −z; heading increases clockwise: π/2 = east). Roads: avenues x ∈ {0,70,140,210}, streets z ∈ {−175,−100,−25,50}, half-width 13 (`ROAD_HALF_WIDTH`). Blocks are the 44×44 squares between roads. Water/marina west of x ≈ −25. Start `START` = (0, 40) heading 0 on a garage display pad; the Sundown Customs shop sits south of street z=50 near x=30.

## M2 — Driving logic (`src/driving.ts`, `tests/driving.test.ts`, new `tests/city.test.ts`)
- `createDriveState(mission: Mission = defaultMission())`; state gains `mission`, `limit` (= mission.seconds), `collected: string[]`, `inBooth: string | null` (id of the booth the car is inside), `lastBooth: string | null` (booth that fired the latest "respray" event), `wantedReason: "camera" | "patrol" | null`.
- Use `onRoad` / `projectToRoad(x, z, heading)` from city.ts (lane direction respects travel direction).
- Checkpoints: `mission.checkpoints`, radius 16, strictly in order. Finish = last checkpoint reached (won) or `elapsed >= limit` (lost) or busted.
- Wanted: first time the car passes within 20 of ANY `camera` landmark → heat 60 (3★), 3 cops, event "wanted", `wantedReason = "camera"`. If the route avoided cameras, when checkpoint index reaches `max(1, n − 2)` a patrol spots the car → heat 20 (1★), 1 cop, "wanted", reason "patrol". Never both.
- Stashes: within 7 of an uncollected `mission.stashes` entry → push id to `collected`, event "stash".
- Resprays: every `landmarks("respray")`; latch per booth (enter → event "respray" once while inside; re-arm on leaving); `applyRespray` sets `resprayUsed` (one successful respray per run).
- Keep exports: `DriveControls`, `DriveEvent` (+ "stash"), `Cop`, `MAX_STARS`, `starsFor`, `stepDrive`, `copPose`, `applyRespray`, `runScore`, `livePayout`. Keep `RESPRAY` (= first respray landmark) and `CHECKPOINTS` / `RUN_SECONDS` as deprecated aliases derived from `defaultMission()` so older imports still compile.
- Scoring: finish 2500 + checkpoints×300 + stashes×750 + drift×3 + boost×2 − elapsed×6 − collisions×125 − stars×150 + 1000 clean-getaway bonus (won, wanted, no stars left). `livePayout` = checkpoints×300 + stashes×750 + drift×3.
- Tests: full rewrite for the grid + missions (drive a mission by steering at nodes; camera trigger; patrol trigger; stash pickup; respray latch/re-arm; busted; timeout at `limit`; lane-direction projection both ways). `npm test` must pass.

## M3 — The Plan (`src/planmap.ts`, `src/PlanLocked.tsx`, `src/plan.css`, `tests/planmap.test.ts`)
The planning map is the headline Unlayer mechanic: the saved map pixels become the mission.
- `renderPlanMap(): string` — 1200×960 PNG data URL using `MAP`/`worldToMap`: GTA pause-map style (dark navy water, teal-grey land blocks, light road grid with street names small, landmark icons: garage (green "START"), 3 drops (gold flags + names), cameras (red camera glyph + faint radius), Spray & Pray (pink spray can), stash crates (gold "?" crates)), a legend column on the right (x > 940): title "THE PLAN", instructions: "1 Draw your getaway route from START to a drop in any bold colour. 2 Circle stash crates in YELLOW to grab them. 3 Cameras on your route = wanted stars." Base map colours must be muted so ink is detectable.
- `analyzeInk(base, edited, width, height)` — PURE. Inputs are RGBA `Uint8ClampedArray`s of the base map and the saved map at the same size (sample every 2–3 px). Ink = pixels that changed noticeably from base (colour delta), inside the map area. Classify: YELLOW-ish ink (hue ≈ 40–70°, saturation high) → `stash`; all other ink → `route`. Return world points (via `mapToWorld`) for each, plus pixel counts.
- `missionFromInk(ink): Mission` — PURE. Mark an edge "drawn" if ≥ 35% of samples along it have route ink within 9 world units. Destination = the drop with most route ink within 22 units (else the drop nearest the ink point farthest from the garage; if no ink at all → `defaultMission()` with a note). Path = `shortestPath(GARAGE_NODE, dest.node, e => e.length * (drawn ? 0.25 : 4))`. `drawnShare` = drawn length / path length. Stashes = crates with yellow ink within 14 units. Notes: 2–4 punchy Nico lines (e.g. drew through 2 cameras → "Two cameras on that route. You’ll be famous."; gaps filled → "Your route had gaps. I filled them in."; stashes). `fromDrawing: true`.
- `planFromImages(baseUrl, editedUrl): Promise<Mission>` — draws both to canvases at 1200×960 and runs the above.
- `PlanLocked` component: props `{ mapUrl: string; mission: Mission; onStart(): void; onRedo(): void; onNicoRoute(): void }` — full-screen "PLAN LOCKED" GTA screen: the saved map image with an SVG overlay of the snapped route (animated dashed magenta GPS line), destination flag, checkpoint dots, marked stash rings, cameras on route pulsing red; side panel with DESTINATION, DISTANCE, CAMERAS ON ROUTE (heat forecast as stars), STASHES MARKED, YOUR INK (% drawn), Nico’s notes as phone bubbles; buttons START THE RUN / REDRAW / USE NICO’S ROUTE. Mobile-friendly.
- Tests with synthetic RGBA arrays (draw lines into a blank array via `worldToMap`) covering: route along the east side → destination causeway/motel as drawn; yellow circle marks a crate; no ink → default mission; gaps filled.
